A tiny deterministic program that writes one original horror sentence — a single line under 200 characters that frightens a reader in one breath — to `entry.txt`.

## Run it

```sh
python3 main.py
```

The entry is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `./output/entry.txt`). The program validates its own output first: exactly one line, one sentence, under 200 characters, valid UTF-8.
